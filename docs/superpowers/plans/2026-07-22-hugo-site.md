# Hugo Static Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert <www.blaskapelle-badwiessee.de> from Jimdo to a Hugo static site on GitHub, deployed via Netlify, with no visual or structural changes.

**Architecture:** Scrape the live Jimdo site to capture all HTML, CSS, JS, and images. Use scraped CSS verbatim in `static/css/`. Extract nav/footer into `layouts/_default/baseof.html`; each page becomes a Hugo template wrapping its content area. Text content migrates to markdown files; structured data (events, gallery) to YAML.

**Tech Stack:** Hugo 0.147.0, Netlify (hosting + forms), GitHub (source), GLightbox (gallery lightbox fallback)

## Global Constraints

- Hugo version: 0.147.0 (set in `netlify.toml` and used locally)
- All static asset references use absolute paths: `/css/...`, `/images/...`, `/js/...` — never relative paths or Hugo's `relURL`/`absURL`
- Actual URL structure (from scrape): `/blog/`, `/galerie/`, `/kontakt/`, `/termine/`, `/chronik-1/`, `/ueber-uns/musikanten/`, `/mach-mit/` (top-level, not nested under über-uns), `/ehrentafel/`
- No `über-uns/index.html` exists on live site — "Über uns" nav dropdown links directly to `/ueber-uns/musikanten/`
- Blog posts live at year paths (`/2017/…`, `/2020/…`, `/2021/…`), not under `/blog/`
- All Jimdo JS (`web.js`, `ckies.js`, `cookieControl.js`, `at.js`) is platform-specific — do NOT copy; use GLightbox for gallery
- CSS: use `layout.css` (from `u.jimcdn.com`) as site theme; `web.css` as reference only
- No visual or structural changes from original site
- German text preserved verbatim — no translations
- Git: always `cd <path> && git <cmd>`, never `git -C`

```typescript
import * as pulumi from "@pulumi/pulumi";
import * as netlify from "@pulumi/netlify";

const config = new pulumi.Config();
const repoUrl = config.require("repoUrl");           // e.g. https://github.com/thetillhoff/music-clone
const repoBranch = config.get("repoBranch") ?? "main";
const customDomain = config.get("customDomain");     // e.g. blaskapelle-badwiessee.de

const site = new netlify.Site("blaskapelle-site", {
    name: "blaskapelle-badwiessee",
    repo: {
        provider: "github",
        repoUrl: repoUrl,
        branch: repoBranch,
        command: "hugo --minify",
        dir: "public",
    },
});

if (customDomain) {
    new netlify.SiteDomain("custom-domain", {
        siteId: site.id,
        domain: customDomain,
    });
}

export const siteId = site.id;
export const siteUrl = site.sslUrl;
```
